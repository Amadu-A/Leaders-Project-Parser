# Исследование источника и ограничения

Проверено 13.11.2026; `main` повторно сверен 16.11.2026 и не изменился: `839d419432fc25bc988e5871f7e53f6d282a2e77`. Прочитаны LLM_CONTEXT, ENGINEERING_GUIDELINES, FRONTEND_GUIDELINES, INFRASTRUCTURE_INSTRUCTIONS и services.yaml из [репозитория инфраструктуры](https://github.com/Amadu-A/shared_infrasktructure). В проекте не используются shared runtimes, brokers, LLM/VLM/OCR.

HTTP 200 получен для robots.txt, каталога, карточки `1657043757`, её контактов и `/legal/terms`. Robots разрешает `/`, запрещает `/api`, `/cabinet`, `/admin`, `/auth`, `/login`, `/register`, `/club/residents`. В видимых условиях не обнаружен отдельный запрет парсинга; это не заменяет специальное разрешение владельца.

Публичный JavaScript-интерфейс обращается к `/api/v1/companies`, справочникам и публичным данным карточек. Пользователь **явно подтвердил разрешение владельца** на такой автоматический сбор. Это отражено в `SOURCE_API_ACCESS_APPROVED`; без разрешения browser resource loader блокирует запрещённые robots API. Авторизация не требуется для доступного каталога; `/api/v1/me` возвращает 401 и для сбора не нужен.

Обычный HTTP-ответ каталога — около 72 КБ, карточки и контактов — около 44 КБ. В нём нет организаций, руководителя и контактов: это Next.js/client rendering. При исследовании 13.11.2026 Chromium отображал 37 710 компаний, 100 на первой странице и 378 страниц. Проба 16.11.2026 получила **37 715 компаний** и два непересекающихся списка по 100 записей. Это наблюдения, не жёсткий лимит: job считывает актуальное количество во время запуска.

Дальнейшая проверка 16.11.2026 подтвердила полноценный публичный HTTP/JSON-протокол. Основной режим использует `/api/v1/companies?role=designer&sort=rating&dir=desc&limit=100&offset=0&legalStatus=active`, затем передаёт выданный сервером `nextCursor` в параметре `cursor` без декодирования. Результат совпал с проверенным `offset=100`; списки не пересекаются. Последняя страница содержала 17 записей и `nextCursor: null`, актуальный `total` был **37 717**. Chromium в основном режиме не нужен.

`GET /api/v1/companies/{inn}` возвращает строковый `inn`, отдельные `leaders` и `founders`, все `contacts` с типами `phone`, `email`, `website`, а также официальный `website`. Проверены физические лица типа `individual`; основная карточка не требует входа. Отдельный API `/api/v1/companies/{inn}/contacts` возвращает 404 и не используется: оба набора полей берутся из одного подтверждённого ответа. Bundle текущей компании хранится только в RAM до обработки контактов. Проба трёх компаний полностью прошла; конкретные контактные значения в технические логи и файлы не записывались.

При доработке КПП и выручки 16.11.2026 проверено: `kpp` в карточке ИНН `7708196924` — строка `770101001`. Текущая `revenue` элемента каталога выражена в **рублях**: у `1657043757` получено `5843594000.0` (год 2025), то есть `5843.594` млн ₽. Другие две проверенные суммы — `8531617000.0` и `25311813000.0` рублей. Поля истории и процент изменения не используются. Для HTML берётся только основное отображаемое значение строки, с преобразованием млрд → млн.

Пагинация находится в `nav[aria-label="Страницы компаний"]`: `button[aria-label="Следующая страница"]`, активная кнопка `[aria-current="page"]`. На последней странице Next disabled. Сервис нажимает кнопку, проверяет новый номер и изменившийся набор URL. В live-пробе кнопка открыла `https://leaders-project.ru/companies/projecting?page=2&size=100`. В query не подставляется предположительный `page`: реальный URL браузера сохраняется вместе с внутренним cursor. Фрагмент `#lp-page=N` не отправляется на сервер источника.

Селекторы данных из предоставленных примеров:

| Поле | Scope |
|---|---|
| Компании | `a[href="/companies/{10–12 цифр}"]`, без фильтров регионов |
| Руководитель | `section#a-leaders`, отдельный узел должности + соседний узел ФИО |
| ИНН | `section#a-requisites`, строка с подписью `ИНН` |
| КПП | `section#a-requisites`, строка с подписью `КПП` |
| Выручка | Строка одной компании в каталоге, основной span блока с графиком `aria-label="Выручка: …"` |
| Контакты | `section[aria-label="Как связаться с компанией"]` |
| Телефоны / email | Все `a[href^="tel:"]` / `a[href^="mailto:"]` внутри scope |
| Официальный сайт | Блок с отдельной подписью «Сайт», без офисов и соцсетей |

Исходные пользовательские HTML-примеры включены как offline fixtures; скачанные страницы не архивируются. Полный сбор никогда не запускался. Статус итогового live smoke и Docker-проверки фиксируется в `docs/validation.md`; offline-тесты не выдаются за подтверждение production deployment на aistation.
